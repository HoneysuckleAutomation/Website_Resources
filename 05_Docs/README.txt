Recommended embroidery settings
-------------------------------
- Default finished badge size: 2.25 in diameter
- Minimum finished badge size: 1.75 in diameter
- Thread: 40 wt polyester
- Main thread color: dark green (#143629)
- Optional accent thread: gold (#B88A2A)
- Border: satin stitch
- Filled icons: tatami/fill stitch
- Avoid auto-digitizing tiny flower details; keep top motif bold

Approved icon system
--------------------
- Enterprises: stacked blocks
- Automation: gear
- Scoring System: target
- Blink Timelapse: camera + arc arrow

Notes
-----
- Text labels are outside the circle to improve stitchability.
- For very small hats, use the hat variants instead of full badges.
- For left chest polos/jackets, use the chest variants.
